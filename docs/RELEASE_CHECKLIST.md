# 发布前检查清单

- [ ] 确认项目名称、所有者、公开仓库地址和准确的上游基线。
- [ ] 在单独的发布候选目录审查文件清单；排除私人音频、模型、任务、日志、路径和截图。忽略规则不等于安全审计。
- [ ] 分别核实 RVC、pymss、Unlock Music、Pedalboard、FFmpeg、各模型和权重的许可及分发条件。
- [ ] 在干净的 Windows 环境实际安装、取得必要资源并启动；记录版本、硬件和失败项。
- [ ] 用可公开素材验证训练和歌曲处理，检查原版回归；明确模拟与真实推理。
- [ ] 复核依赖、Git 历史、密钥、截图、CI 和发布包内容。
- [ ] 补齐中英文文档、版本、变更日志、安全联系渠道、上游提案与申请材料。
- [x] 已获所有者同意创建公开仓库；仓库目前只有筹备说明与许可证。
- [ ] 公开源码前完成隐私、许可和发布内容审查；正式版本尚未发布。
- [ ] 上游讨论与 Kilo 申请先准备材料，不自动发送或接受条款。

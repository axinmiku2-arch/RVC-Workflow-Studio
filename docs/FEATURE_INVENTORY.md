# 现有功能清单（基于代码和现有说明）

| 模块 | 代码中可见的能力 | 边界 |
| --- | --- | --- |
| 一键训练 | 音频检查、任务记录、训练子进程、日志、检查点、续训和导出 | 不同硬件与全新环境尚未全面验证 |
| 一键分离 | 多文件、音轨、试听、模型下载、分离、去和声、去混响、降噪、阶段结果及导出 | 效果依赖模型和素材，模型许可分别处理 |
| 单次歌曲工作流 | 分离／清理、RVC 转换、可选效果、伴奏合成、试听、导出和阶段复用 | 主要集成在单次推理；批量增强流程未证实 |
| 音乐导入 | 浏览器本地解密支持的 NCM/QMC 等格式，并可单独下载 | 特定版本可能不支持；不保证所有加密格式 |
| 原版功能 | 原 WebUI、训练、推理及既有分离入口仍存在 | 本轮完整回归和干净安装尚待完成 |

转换链检查模型和索引哈希，对输出长度偏差超过 0.1 秒拒绝合成；合成前重采样、保持双声道并在峰值过高时整体衰减。功能存在不等于所有输入或硬件均已验证。

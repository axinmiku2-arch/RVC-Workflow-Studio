# 项目审计（初稿）

审计日期：2026-10-30。工作目录为便携部署，不存在 `.git`：没有可供核验的提交历史、远程地址或上游基线。不能由文件名确定作者和改动来源。

## 架构

- `webui.py` 提供 RVC 原 WebUI，并接入单次推理的增强流程和音乐导入。
- `training_wizard.py`、`rvc_wizard/` 管理训练任务、音频分析、子进程、检查点和日志。
- `separation_wizard.py`、`rvc_separation/` 管理分离模型、音轨、试听、阶段缓存和导出。
- `rvc_conversion/` 把分离、RVC 转换、Pedalboard 效果和伴奏合成串联；GPU 操作使用 `tools/gpu_task_lock.py`。
- `rvc_music/` 提供本地音乐导入与浏览器解密；包含第三方 Unlock Music worker，须保留来源和许可。
- `infer/`、`train/`、`configs/`、`tools/`、`i18n/` 包含 RVC 及其依赖实现。便携运行时、权重、任务和导出均是本机数据。

## 运行环境与限制

本机检查：Windows、Python 3.12.10、PyTorch 2.7.1+cu118、Gradio 3.14.0、NumPy 1.26.4；CUDA 可用。现有启动脚本依赖本机 `runtime/python.exe`、`ffmpeg.exe`、`ffprobe.exe` 与模型资源。效果器安装脚本只提供 Windows CPython 3.12 x64 包。CPU、其他系统和全新安装尚未验证；原项目支持范围不代表增强功能已完成跨平台验证。

## 优先风险

1. **发布阻断：隐私。** 现有训练验收 HTML 和专用脚本含有私人素材名称及本机路径；任务、输出、模型目录均可能含私有信息。已有忽略规则只是第一道防线，公开前仍须检查实际暂存内容及截图。
2. **发布阻断：许可。** RVC 根许可证为 MIT，但模型与二进制不自动继承该许可；现有清单中 Deux 标记为 CC BY-NC 4.0，Sucial Fused 标记为 CC BY-NC-SA 4.0，其他权重需逐一核对来源和权利。FFmpeg 构建、Pedalboard、pymss 和浏览器 worker 的来源及再分发条件尚需完整核验。不要捆绑未核实文件。
3. **发布阻断：可复现安装。** 当前安装依赖便携运行时、本机权重和根目录 exe；从干净环境部署和模型取得尚未验证。
4. **维护风险：无基线。** 无本机 Git 历史或明确上游版本，不能准确归属全部改动；新建仓库也不会自动恢复历史。
5. **安全：服务暴露。** 候选 WebUI 默认监听本机；用户可通过环境变量主动设为 `0.0.0.0`。本机文件操作和模型加载在不可信网络上需要认证和隔离，公开网络部署未审计。
6. **共享任务状态。** 转换管理器启动时会把其目录中未完成任务标为中断；多实例同时访问同一目录可能产生状态冲突。避免重复实例，后续应完善跨进程所有权。

自动识别与解密音乐

公开源码说明：由于预构建 worker 的第三方依赖及授权链尚未核查完毕，公开源码暂不附带该 worker，因而不能解密 NCM／QMC。下文描述本机完整版本的能力，不代表公开源码版本已具备此功能；普通音频导入不受此限制。

在原 WebUI 的“单次推理”中，将文件直接拖入“待处理音频”。普通音频直接载入；受支持的加密音乐自动解密，成功后可在同一个播放器试听。

  1. 拖入或点击选择一个音频文件。
  2. 等待提示“音频已导入”或“解密完成”。
  3. 解密成功后，可使用单独的“下载解密音乐”，无需选择音色或运行转换。
  4. 也可直接点击“转换”，继续执行已有的分离、转换、效果与歌曲合成功能。

格式与处理方式

使用固定版本的 Unlock Music 浏览器模块；支持 NCM、旧版 QMC0／QMC3／QMCFLAC／QMCOGG、BKCM、TKM，以及该版本支持的 TM 格式。MFLAC／MGG 沿用实验性本地识别，无法取得本地密钥时提示不支持。新版加密格式不保证兼容。

NCM 同时检查文件头，因此即使后缀被误改也能识别。普通音频根据文件内容识别。损坏文件、无法解码和不支持的加密版本会提示失败，并清除待处理素材，避免误用前一个文件。

解密在本地浏览器的独立工作线程中执行，解密结果仅送入本机 WebUI。外部封面请求、密钥查询和使用统计已停用。无需显卡、AI 模型或新增 Python 依赖。

下载与音质

下载保留解密得到的原音频格式，不统一重新编码成 WAV。完整转换使用原始解密音频；播放器裁剪使用另一份副本，下载内容保持完整。导入缓存单独保存在 logs/music_import，不会清理训练或分离任务。

首版面向单次推理，每次导入一个文件，最大 512MB。刷新后正在后台运行的转换仍按原任务恢复方式处理；导入页面中的下载入口对应本次成功导入的文件。

验证记录

受控生成的 NCM／QMC 样本完成浏览器拖入、中文名称、错误后缀、缺少元信息、连续导入、下载与失败保护检查。无损样本的解密输出 SHA-256 与原始 FLAC 相同；完成直接 RVC 转换及分离→转换→效果→合成后，独立下载的内容仍保持一致。实际歌曲的加密版本仍以真实文件验证为准。

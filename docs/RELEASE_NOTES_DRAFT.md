# v0.1.0-beta 发布说明草稿（未发布）

RVC Workflow Studio 是基于 RVC 的独立增强工作流，包含训练向导、音频分离向导以及单次推理中的声音转换、效果与歌曲合成。原版 RVC 已提供声音转换、训练和分离能力；本项目主要整合操作流程。

当前开发环境为 Windows x64。候选源码的 59 项轻量检查及 2 项环境检查通过，包含模拟任务；Leap Xe 和温和去混响已用 3 秒合成信号分别完成真实 GPU 推理检查。另用 4 秒合成音频和本机资源完成一次分离、RVC 转换、效果与合成的真实核心链检查；另使用 16 秒合成信号完成一次一轮真实训练与索引生成；训练页素材导入与分离页的合成音频处理和导出已做浏览器检查；真实歌曲听感、主 WebUI 浏览器全流程、长时间训练和全新安装尚需完成。模型及第三方组件可能具有独立的许可证和使用限制。尚未形成安全审查完成的候选包，不得据此宣称版本已发布或可从源码复现安装。

RVC · 单次推理

歌曲拖进来，转换后直接试听。

在原 WebUI 中完成分离、音色转换、添加效果与伴奏合成。转换干声始终独立保留。

从这里开始

  1. 选择音色模型，上传待处理音频。现有变调、索引和音高算法仍按原方式使用。
  2. 如果素材带伴奏，勾选“分离音频”。默认 Leap Xe＋温和去混响。
  3. 按需要勾选“添加人声效果”或“合成完整歌曲”，点小箭头打开高级设置。
  4. 可先点“试处理30秒”；满意后点原“转换”按钮处理整首。
  5. 在“试听结果”中切换干声、效果人声、合成歌曲和各阶段人声。

清理与效果分开选择

去和声、去混响、降噪发生在转换之前。去和声用于主唱提取，不能保证保留指定歌手的所有叠唱；加强去混响也可能减少和声。只开启需要的步骤，先用短段试听。

效果适合的方向
清晰贴近温和均衡、动态控制。
自然空间少量空间混响。
空灵氛围宽混响、轻微回声与合唱效果。

强度默认35%，0为完全旁路。效果放在转换后，另存为效果人声，不覆盖转换干声。

把人声与伴奏合回歌曲

启用分离后才能合成歌曲。添加效果时使用效果人声，否则使用转换干声；伴奏保持原来的双声道。人声和伴奏音量默认0dB，峰值过高时整体降低音量以免削波。

伴奏默认保留原调。可独立调半音，也可点“跟随人声调性”：人声−14时伴奏−2；人声±12时伴奏不变。试听后改预设、强度、音量或伴奏变调，点“更新效果／合成”，不用重新分离或转换。

试听满意后导出

展开“试听满意后导出到文件夹”，勾选干声、效果人声、歌曲或原伴奏。输入目标路径或点击浏览文件夹，选择24位 WAV 或 FLAC，再点“导出整首结果”。默认文件夹是项目的 exports/conversion。

重名自动编号，已有文件不覆盖。输出采样率遵循原页面重采样设置。短段文件可单独下载试听，但不会被当成整首正式导出。

任务恢复与重试

关闭网页后任务继续。刷新或点击“恢复最近任务”可以找回进度、参数和结果。停止只结束本次转换子进程；点“重试／继续”复用已完成的阶段。分离失败不会继续转换原音频。

任务目录为 logs/conversion_pipeline，不与独立分离页、训练项目共用任务记录。训练与分离转换共享显卡队列。若素材、音色或转换参数变化，需要重新点击转换；仅更改后处理参数时可快速更新。

组件与接口

复用现有分离权重。效果器是隔离安装的 Pedalboard 0.9.25，位于 tools/audio_fx，安装包按公开SHA256校验；不升级原有 NumPy、Torch、Gradio。组件的许可文件随安装包保留。

原 infer_convert、infer_change_voice 接口的参数与返回保持兼容。新流程使用 infer_convert_pipeline、infer_convert_preview、infer_convert_postprocess、infer_convert_export。

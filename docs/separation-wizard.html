RVC 一键分离向导

从歌曲到干声

  1. 拖入音频或视频，点击导入素材。多音轨视频可逐个选择音轨。
  2. 默认开启 Leap Xe 分离与温和去混响，保留人声。伴奏可以同时保留。
  3. 选择副歌等典型片段，先试处理 30 秒。试听原声、分离人声与最终干声。
  4. 满意后处理全部整首。关闭网页不会停止后台任务；刷新可找回任务。
  5. 试听完整结果，勾选文件及结果，浏览或填写导出文件夹，点击导出。

如何勾选功能

伴奏密集时可以对比 Leap Xe 与 Deux；想快速试效果可用现有 ViperX。去和声适合提取主唱，但会移除部分重叠演唱。温和去混响优先保留音色和尾音；加强档处理延迟回声，也可能减少和声与叠唱。降噪只在噪声明显时开启，过度清理可能损伤气声。已经提取的人声可以关闭分离，直接清理。

不同歌曲的效果不同，请以试听为准。没有自动切除间奏、气声或静音。

继续、模型与导出

停止只结束本任务的子进程，完整阶段保留。继续 / 重试会复用未改变的步骤。更换功能后需重新处理；试段与整首分别保存。显存不足时会缩短同一模型的片段长度，并显示实际参数。训练、原 WebUI 与分离的 GPU 执行入口共享任务锁，排队运行。

模型管理支持续传和重试，只有下载校验与真实推理验证通过后才可用。默认导出 44.1kHz、双声道、24 位 WAV，也可选 FLAC 或单声道。重名自动编号，必要时仅降低音量以防削波。试听缓存不能作为整首导出。导出的干声可拖入训练向导，不会自动开始训练。

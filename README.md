# RVC Workflow Studio

本项目是 [RVC](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI) 的独立增强工作流，目标是整合训练向导与音频分离、声音转换、效果和歌曲合成。

**状态：筹备中。** 源代码、安装方式和第三方模型许可仍在审查，本仓库尚不能安装使用，也没有正式发行版本。

RVC 原项目已经支持训练、声音转换和音源分离。本项目致力于将相关操作组合为更易使用的工作流，并非 RVC 官方版本。

上游代码采用 MIT 许可证；第三方依赖和模型有各自的许可证及使用条件，正在逐项核实。

---

An independent workflow enhancement for RVC, focusing on guided training and a connected audio production workflow. This repository is under preparation and does not yet contain an installable release. Third-party components and model terms are being reviewed.
